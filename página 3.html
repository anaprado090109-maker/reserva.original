Conheça o trabalho das nossas desenvolvedoras

Ana Julia foi responsável, em conjunto com Mariana, pelo desenvolvimento da programação do software. Utilizando Python e o ambiente de desenvolvimento Visual Studio, contribuiu para a implementação da lógica e das funcionalidades necessárias ao funcionamento do sistema. Sua participação envolveu a organização do código, o desenvolvimento de recursos da aplicação e o uso de ferramentas de programação para auxiliar na execução, nos testes e na identificação de possíveis erros. Seu trabalho contribuiu para transformar a proposta do projeto em uma solução tecnológica prática, organizada e voltada às necessidades dos usuários.

Maria Clara foi responsável pelo desenvolvimento visual e pela estruturação do site, utilizando HTML, CSS e Bootstrap no Visual Studio Code (VS Code). Seu trabalho envolveu a criação e a formatação das páginas, a organização dos elementos e a definição de cores, espaçamentos, tamanhos e estilos. Com atenção à apresentação visual e à experiência do usuário, trabalhou para construir uma interface organizada, intuitiva e agradável. O uso do Bootstrap auxiliou na estruturação dos componentes e na criação de um layout consistente, contribuindo para apresentar o projeto de maneira profissional e valorizar a solução oferecida aos clientes.

Mariana foi responsável, em conjunto com Ana Julia, pelo desenvolvimento da programação do software. Utilizando Python e o ambiente de desenvolvimento Visual Studio, participou da construção da lógica do sistema e da implementação das funcionalidades previstas para o projeto. Durante o desenvolvimento, contribuiu para a organização do código e para o uso de ferramentas que auxiliam na escrita, na execução e na depuração da aplicação. Sua participação foi importante para construir uma solução tecnológica funcional, com foco na praticidade, na organização e na otimização das tarefas realizadas pelos usuários.
